# V1.0 security review: evidence pack (V10-S6a)

- **Base:** `main` at `67ce701` (`67ce7016b08b9a1e35843c773f5bdec73114d8af`).
- **Date:** 2026-11-21.
- **Evidence only. Verdicts, findings and sign-off are in V1.0-SECURITY-REVIEW.md, written by the auditor (V10-D4 (a)).**

This pack collects, for each component of [ADR-0018](../adr/ADR-0018-v10-stabilization-multi-agent.md) section 5.1, the
evidence for each item of the checklist. It classifies nothing as passed, failed or accepted.

## How to read it

- **Line references** are to the files at `67ce701`. `file:N` is one line; `file:N-M` is a range.
- **Tests** are named `area :: short title`, as the cases of `tests/Run-Tests.ps1` are named (titles shortened). "Install
  e2e" means a `Step` of `tests/e2e/Invoke-InstallE2E.ps1`, run in CI only.
- **Observation column:** facts only. A fact that may matter to the review is marked `OBSERVACAO`: what was seen,
  where, and why it may matter. It is not a finding and not a verdict.
- **`SEM EVIDENCIA ENCONTRADA`** means the executor found no test, line or document for that item. It is not a
  conclusion that the property is false.
- The nine release gates are common to several components. Their evidence is in the next section, and the component
  tables refer to it.

**Observations on the gates:**
- `OBSERVACAO`: the single-assignment tests match the pattern `<name>\s*=`. A variable set another way
  (`Set-Variable`, `New-Variable`, a `[ref]`) would not match that pattern. Today `src` contains none of these
  cmdlets (search above), so this is about the form of the test, not about the code. It bears on item 3, "no option,
  variable or file opens a gate": the static proof of that item rests on this pattern.
- `OBSERVACAO`: `Register-AtmProvider` replaces an already registered provider with the same id
  (`src/lib/Engine.Audit.ps1:99`), and the B1 exception is granted by id (`Engine.Clean.ps1:174`). The generic test
  factory refuses shipped ids (ADR-0018 S3 record, `:639-642`). Registration itself does not. Shipped copies load only
  providers listed in the verified manifest (`src/agent-temp.ps1:125-130`). It bears on item 3, "a provider cannot
  weaken a gate", for a provider loaded outside the verified manifest (a development copy).
