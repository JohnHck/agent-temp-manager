# V0.2 TUI diagnostics area: manual acceptance checklist

Status: **NOT TESTED** in a real console. P5-A was validated headless only (rendered frames, injected keys); the
checklist below is the manual acceptance planned for FINAL-B and carried to the release candidate (FINAL-C), still not
run. A headless pass is not a manual pass.

## Rules for the tester

* Use a development copy (`src\agent-temp.ps1`) or an installed V0.2 build on a machine where a read-only run is
  acceptable. The diagnostics only read; they never stop, start or change anything.
* Do not start or terminate processes, services or VMs to provoke a state, and do not change permanent console
  settings (registry, default profiles, fonts). Window size and code page changes below apply to the current window
  only and end with it.
* Record each line as PASS, FAIL or NOT TESTED, with the terminal, the shell and the language.

## Terminals and shells

Run the whole list in each combination available:

| Terminal | Shell |
|---|---|
| Windows Terminal | Windows PowerShell 5.1 |
| Windows Terminal | PowerShell 7 |
| Console host (conhost) | Windows PowerShell 5.1 |
| Console host (conhost) | PowerShell 7 |

Start: `agent-temp` (installed) or `powershell -NoProfile -ExecutionPolicy Bypass -File .\src\agent-temp.ps1`.

## Checklist

1. The main menu shows the V0.1 entries (`1`-`9`, `P`, `L`, `R`, `H`, `Q`) and `D` Diagnostics V0.2.
2. `D` shows the busy screen with the "may take a while" warning, then the area: observation time, the warning "The
   results do not authorize deleting files or terminating processes", the legend for `*`, and nine categories.
3. Arrows, PgUp/PgDn, Home/End move the selection; Enter opens; Esc and Backspace go back; the footer always shows the
   keys.
4. Summary: partitions `IN_USE`/`UNKNOWN`, processes verified/unverified, services, VMs, worktrees with "not observed"
   when their collector was not read; no line wider than the window.
5. Coverage: every collector listed, including `process-cwd`, `handles`, `worktree-discovery` (`NOT_OBSERVABLE`),
   `profile-discovery` and `dependency-graph`; Enter shows the reasons and the elevation wording.
6. Partitions and the graph: a detail shows evidence, coverage and edges with `[D]`, `[A]` or `[?]`; a graph node
   without its own finding reads "reference without its own finding".
7. Paging: a long list moves page by page and the footer shows `position/total`.
8. Navigation, paging and details do not run the diagnostics again (no busy screen); leaving with Esc and entering
   with `D` again shows the same observation time.
9. `U` shows the busy screen and a new observation time; the screens above the area are closed.
10. Resize the window while in the area (smaller and larger): the next key redraws within the new size.
11. 60x20: in a conhost window, run `mode con: cols=60 lines=20` (this window only), start the TUI, repeat 2-9; every
    text that does not fit is wrapped or ends with an ellipsis, and the footer stays visible.
12. ASCII: start with `-Ascii` (or `$env:ATM_ASCII = '1'` in this window); only ASCII characters appear.
13. Unicode: in Windows Terminal without `-Ascii`, box characters and accents (pt-BR) render correctly.
14. Languages: `-Lang pt-BR` and `-Lang en-US` show every text of the area in that language.
15. Return to V0.1: from the area, Esc returns to the main menu; `1`, `4` and `9` still work, and `R` re-audits there
    (inside the area `R` does nothing).
16. Physical keyboard: the same keys work typed on a physical keyboard (not only injected).
17. Incomplete coverage: in a window that is **not** elevated, the area shows the collectors that could not be read
    completely (`PARTIAL`, `DENIED`, `NOT_OBSERVABLE`) with their reasons and the elevation wording; no count of such
    a collector reads as zero or "none" without the `*` marker.
18. No destructive action: in the whole session no screen of the area offers to delete, terminate, stop or change
    anything, no confirmation phrase is asked, and leaving the TUI changes nothing (`agent-temp verify` still exits 0
    on an installed copy).

## Not exercisable safely in a real console

* **Diagnostics failure and the outdated marker.** Provoking a failure would require changing the system or stopping
  processes, which this checklist forbids. They are covered by headless tests (an injected failing runner: safe code
  shown, the previous result kept and marked outdated, no automatic retry). Status here: NOT TESTED; to be exercised
  in a disposable VM in FINAL-B if a non-interfering method is available.
